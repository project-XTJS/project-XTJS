# 错别字公开数据训练与评测

该流程使用 CSCD-NS、ECSpell 的 law/odw 数据及 NLPCC2023 公开开发集。原始数据、训练权重和预测缓存不进入 Git；默认产物目录建议放在 `/data/xtjs-models/typo-training/<run>`。

## 1. 下载和冻结数据

在独立 Python 环境安装：

```bash
pip install -r requirements-typo-training.txt
python tools/download_typo_public_data.py /data/xtjs-models/typo-training/public-v1/public
python tools/prepare_typo_training_data.py \
  --cscd-dir /data/xtjs-models/typo-training/public-v1/public/cscd-ns \
  --ecspell-dir /data/xtjs-models/typo-training/public-v1/public/ecspell/Data/domains_data \
  --nlpcc-file /data/xtjs-models/typo-training/public-v1/public/nlpcc2023/data/data.txt \
  --output-dir /data/xtjs-models/typo-training/public-v1/data
```

`download-manifest.json` 固定上游 revision 和文件哈希；`cleaning-report.json` 记录每个来源的保留、排除、错字和原生正确字符数量。清洗器只保留等长汉字替换，并让测试集、外部测试集和开发集优先于训练集去重。

## 2. 训练

先执行 50 个更新步的显存试跑：

```bash
python tools/train_typo_macbert.py /data/xtjs-models/typo-training/public-v1/data/public_typo_dataset.jsonl \
  --model models/typo/macbert4csc-base-chinese \
  --output-dir /tmp/typo-benchmark --benchmark-only --max-updates 50
```

正式主训练使用脚本默认值：BF16、micro-batch 8、梯度累积 8、正确/错误样本 60/40、错误位置损失权重 3、学习率 `2e-5`、最多 2 epochs。每半个 epoch 在开发集评测并保存最佳 F0.5 检查点。

```bash
python tools/train_typo_macbert.py /data/xtjs-models/typo-training/public-v1/data/public_typo_dataset.jsonl \
  --model models/typo/macbert4csc-base-chinese \
  --output-dir /data/xtjs-models/typo-training/public-v1/model
```

若固定候选门槛的误报仍高，可先用 `evaluate_typo_training.py --split train --hard-negative-output ...` 收集最多 2,000 条误报正确句，再用 `--epochs 0.5 --learning-rate 5e-6 --hard-negative-file ...` 补训。补训检查点只有在误报下降、修改精确率不降且召回下降不超过 2 个百分点时才保留。

## 3. 词语规则审核

```bash
python tools/manage_typo_word_rules.py extract /data/xtjs-models/typo-training/public-v1/data/public_typo_dataset.jsonl \
  --limit 200 --output word-rule-review.jsonl
```

审核文件保留完整词语、出现次数、来源和上下文。两位不同审核人分别填写 `first_review` 和 `second_review`；只有两项均为 `approved` 才可编译：

```bash
python tools/manage_typo_word_rules.py compile \
  --base-rules app/service/typo_runtime/word_rules.json \
  --review-file word-rule-review.jsonl \
  --version 2026-09-23.2 --output reviewed-word-rules.json
```

编译器拒绝增删字、多字替换、保护词冲突、同一原词多种改法和同一审核人重复审核。冻结测试集不能用于提取规则。

## 4. 阈值搜索和最终验收

开发集先缓存一次模型原始候选，再搜索 `0.90/0.93/0.95/0.97/0.99` 与 `20/30/50/100` 的组合：

```bash
python tools/evaluate_typo_training.py /data/xtjs-models/typo-training/public-v1/data/public_typo_dataset.jsonl \
  --model /data/xtjs-models/typo-training/public-v1/model \
  --split dev --cache tuned-dev-candidates.jsonl --report tuned-dev-report.json \
  --rules reviewed=reviewed-word-rules.json --search-thresholds
```

冻结模型、词表和阈值后，对 `test`、`test_ecspell_law`、`test_ecspell_odw` 和 `test_nlpcc` 只执行一次最终评测。报告分别给出候选和正式结果的精确率、召回率、原生正确文本每万字误报、待复核数量及门槛结论。模型清单初始为 `accepted=false`；只有正式结果达到 98% 位置精确率、98% 修改精确率、每万字误报不超过 1，并具有至少 200 处真实错字、10 万正确字和 100 项自动采纳结果时，才可进入发布流程。

训练产物不会修改 `TYPO_ACCEPTED_MODEL`，也不会替换线上模型。公开集通过仅表示公开基准通过，标书场景仍需单独验证。
