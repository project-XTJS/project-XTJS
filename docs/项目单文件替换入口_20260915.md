# 项目单文件替换入口

2026-09-15 已发布。

## 使用方法

刷新项目管理页面，在“OCR 进度”文件列表右侧点击“替换文件”，选择正常 PDF。招标文件、商务标、技术标均支持；已识别和待处理文件均可替换。项目正在执行 OCR 或页面正在进行其他操作时，入口暂时禁用。

上传后显示“替换中”，新文件识别成功后再切换项目关联。大文件可能耗时较长，请保持页面打开。替换成功后文件列表刷新，并提示重新检查历史结果。

同一招标文件在当前项目的多个投标组中被引用时，所有对应关联在同一事务更新；其他项目不受影响。旧文件、旧 OCR、历史结果不作物理删除。

## 失败与并发处理

- 新 PDF 识别失败：保留原关联；复用原上传流程回滚本次新上传对象。
- 上传期间项目材料变化：比较上传前输入版本，冲突返回 409，避免覆盖更新后的关联。
- 关联事务失败：全部回滚，保留原关联、输入版本和历史结果引用。
- 上传识别已成功但关联失败：新文档保留，原关联不变；不自动删除已入库文档。
- 响应丢失：页面提示替换未确认完成，并刷新文件列表；不声称服务端必然未提交。
- 切换项目后的迟到响应：仅更新原项目记录，不覆盖当前项目页面与成功提示。

现有数据库触发器负责同步上传清单、解析状态、输入版本及结果历史引用；无需数据库迁移。新增登录保护接口 `POST /api/postgresql/projects/{identifier_id}/replace-document`。

本次没有增加失败状态持久化。“OCR 失败但仍显示待处理”的原有展示限制仍在，替换操作自身会展示错误原因。本次也没有自动替换古北损坏的技术标，仍需用户选择正常原件。
