# 商务标形式审查六项修复验收

2026-09-14 完成实施、回归验证及部署。本次对应业务逻辑审查的第 **1、2、3、4、7、8 项**，不包含其余审查问题。

## 已发布行为

| 项目 | 实现与边界 | 验证 |
| --- | --- | --- |
| 1 金额单位 | 保留元、万元、亿元、万、亿；Decimal 换算并保留精确金额字符串，原 `amount_yuan` 兼容按元读取。单位仅来自对应字段、表格或明确计价声明，缺失或冲突待复核。 | 20万元换算为200000元，超过100000元限价；与贰拾万元一致。人工输入20万元同样处理。 |
| 2 计价口径 | 金额携带币种、年度/合同全周期/单价、年度与包件、计量对象、原文及定位。口径不一致待复核；不从服务年数自动推算。明确的年度限价乘数公式保留换算依据；逐年报价逐项比较。 | 年限价10万与三年总价24万待复核；合同总限价30万可比较；逐年报价中第二年11万能定位超限。 |
| 3 费率规则 | 两个商务标编排入口均传入招标内容。费率使用适用的招标规则；具体业务优先于全项目通用规则，冲突待复核。取消1.5%默认阈值及折扣率固定小于100%的判断；保留边界和0%。同时填写金额与费率时两者均核验。 | ≥5%时2%失败、5%通过；>5%时5%失败；≥0%时0%有效；无规则待复核；否决条件的边界转换有回归覆盖。 |
| 4 限价解析 | 区分已确定、明确不设、未能确定。明确不设显示不适用且不计为子项通过。预算引用按范围关联，明确章节引用保留两处证据；不能解析、金额冲突或范围不明时待复核。 | 同预算可解析时比较；详见需求但未找到金额时待复核；不使用候选最高分或最大金额直接决定限价；百分比报价不免除金额限价核验。 |
| 7 截止日期 | 收集候选和明确的更正关系，沿关系确定有效日期；无关系的冲突待复核。识别不到截止日期仍保留落款日期及位置。保留自然日比较、单一日期放宽及多日期上下文规则。 | 9月1日延期至9月10日采用后者，换行及连续更正有测试；无关系的两个日期待复核；人工改为9月11日后重新比较并判晚于9月10日。 |
| 8 摘要统计 | 按有效附件明细去重统计。日期只统计需要日期的附件，只有pass计通过；缺日期、过晚、待复核分别计数，不要求日期和已跳过单列。签字与公章同一附件同时缺失只算一个附件未通过。 | 截止日期不确定不计日期通过；没有适用日期要求时显示无需日期核验；人工复核后摘要与有效明细重新统计。 |

人工复核保留新增金额和规则依据。旧结果缺少计价口径时不默认推断为合同总价；旧截止日期缺少新版解析依据时需重新检查或人工明确确认，避免人工保存回到旧判断。费率的招标阈值只读，并提供招标规则定位；修改投标响应值不会替换招标规则。人工编辑日期时先标记待核验，保存后由后端比较，前端不凭文本存在直接显示通过。

金额识别优先采用本次报价一览表。表外兜底只采用明确的当前投标总价字段，避免把历史合同总金额或分项表序号当作本次总报价。OCR 原始字符保持原样，未增加自动纠字。
