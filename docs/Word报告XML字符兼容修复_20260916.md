# Word 报告 XML 字符兼容修复

发布日期：2026 年 9 月 16 日。适用：项目结果的 Word 报告导出。

## 原因

“上海数据集团鼎博大厦2026年度内保物业管理服务项目”（标识 `0da620b7-dae8-4f0a-8687-90bb5e1fe9ad`）关联的 `扫描-技术..pdf`，其 PDF 元数据 Producer（制作工具）包含一个 `U+0000` 空字符。导出程序将该属性直接写入 Word 的源文件属性表，python-docx 底层 XML 库拒绝该字符，抛出 `All strings must be XML compatible`。

使用该项目原始属性在旧镜像中已复现。异常发生在 Word 生成阶段，尚未执行报告上传和报告地址更新；本次故障不是 OSS 读写失败，也不需要重新 OCR。

## 修改范围

- 在 Word 输出边界增加统一字符过滤，覆盖正文、表格、报告头部、动态章节与公司标题、Word 核心文档属性。
- 仅去除 XML 1.0 禁止的控制字符、代理码点及 `U+FFFE/U+FFFF`；保留制表符、换行、回车和其他合法 Unicode 字符。
- 不修改 PDF、OCR 原文、已保存审查结果或人工意见，不增加 OCR 自动纠字。
- 不修改数据库结构，不改动业务判定及报告内容筛选规则。

涉及文件：`app/router/postgresql.py`；新增回归：`tests/test_word_xml_compatibility.py`。
